⚡ Conexión con Supabase (Piso Tecnológico)

Puedes vincular tu propio proyecto de Supabase ingresando las credenciales de la API. Se guardarán de forma segura en este navegador mediante localStorage.

📋 Script SQL para Supabase

Para habilitar la base de datos en Supabase, ejecuta el siguiente script en el SQL Editor de tu proyecto. También se encuentra disponible en el archivo supabase_schema.sql en el repositorio.

CREATE TABLE public.reportes_incidencias ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL, sala TEXT NOT NULL, numero_equipo TEXT NOT NULL, tipo_problema TEXT NOT NULL, prioridad TEXT DEFAULT 'Media', reportado_por TEXT DEFAULT 'Docente / Alumno', descripcion TEXT, estado TEXT DEFAULT 'Pendiente' ); ALTER TABLE public.reportes_incidencias ENABLE ROW LEVEL SECURITY; CREATE POLICY "Permitir registro publico" ON public.reportes_incidencias FOR INSERT WITH CHECK (true); CREATE POLICY "Permitir lectura publica" ON public.reportes_incidencias FOR SELECT USING (true);
